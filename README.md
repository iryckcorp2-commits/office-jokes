One funny line about office life: an employee warns the boss that AI is
coming for the job, and the boss promotes the AI instead, so now the AI
is the one approving the time off.

> I told my boss AI was coming for my job. He promoted it, and now it approves my time off.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` (one line, 89 characters) to the output directory. It uses only the Python 3 standard library, needs no network, and two runs produce byte-identical files. It refuses to write an entry that is blank, multi-line, over 199 characters, or contains an em-dash.
